# Future Leaders Movement — site source

Plain HTML/CSS site, no build tools required.

## Files
- `index.html` — Home
- `our-story.html` — Our Story
- `for-companies.html` — For Companies & Nonprofits
- `join-the-movement.html` — Join the Movement (includes coaching access details + application info)
- `for-sponsors.html` — For Sponsors & Donors
- `special-thanks.html` — Special Thanks
- `terms.html` — Terms and Conditions
- `style.css` — shared styling for every page
- `images/` — drop your photos here, then reference them from any page

## Fonts
Space Grotesk (headlines) + Work Sans (body), loaded from Google Fonts via `style.css`.
Requires an internet connection to display correctly — Live Server or GitHub Pages
both provide that automatically.

## Images
Photos are credited on the Special Thanks page. Logo files: `images/logo-icon.png`
(used in header/footer) and `images/logo-full.png` (used on Special Thanks and
Terms pages).

## Preview locally
Open this folder in VS Code, right-click `index.html`, choose "Open with Live Server."

## Publish
Push this folder to a GitHub repo, then turn on GitHub Pages in
Settings → Pages (source: Deploy from a branch, branch: main, folder: / root).
